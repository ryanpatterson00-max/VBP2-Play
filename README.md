# VAGABOND: BLOCK PARTY 2

Playable build of an Animagon Laboratories game in progress. Built from a private repo; this repo holds only the game page.

On a phone: open the page in Safari or Chrome, then Share → Add to Home Screen.

## Credits

All songs are composed in the game's Beat Lab and play on its own engine. Some began as sketches generated with MiniMax Music 3 (Sunlit Sidewalk via AIVA, which runs on it), then rebuilt note by note; the sketches themselves aren't used.
